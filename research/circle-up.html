CSE 340 · Class project

Circle Up.

A user-centered software design project exploring how to build a more approachable social experience.

Design & evaluation

Designing for the people who use it

In CSE 340, I worked on Circle Up, connecting software implementation with user experience and iterative evaluation. The project received a System Usability Scale (SUS) score of 80 during usability testing.

What I took away

Implementation is only part of the story.

Circle Up reflects my interest in the intersection of computing and psychology: understanding how people interact with software and using their feedback to improve the experience.
